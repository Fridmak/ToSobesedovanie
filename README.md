# ToSobesedovanie — DDD billing

Учебный проект: расчёт коммунальных платежей с разделением на слои и элементами DDD.
Консольное приложение считает начисления по нормативу, по счётчику и по двухкомпонентному
тарифу на горячую воду.

## Стек

- .NET 8
- EF Core 8 + SQLite
- DDD: сущности, value objects, репозитории, доменные сервисы
- DI через `Microsoft.Extensions.DependencyInjection`

## Архитектура

```
BillingContext.Domain/          Account, Amount, Tariff, Normative,
                                OccupancyPeriod, ServiceType, интерфейсы сервисов
BillingContext.Application/     DTO и CalculateBillingCommandHandler
BillingContext.Infrastructure/  DbContext, репозиторий, провайдеры тарифов и нормативов
BillingContext.Presentation/    консольный ввод-вывод и точка входа
```

Правило зависимостей соблюдено: Domain не знает про EF Core и консоль,
Infrastructure реализует интерфейсы домена, Presentation собирает всё через DI.

## Что реализовано

- Расчёт по нормативу: `объём = количество жильцов × норматив`.
- Вспомогательный расчёт по разнице показаний счётчика (в основном сценарии показания пока не передаются).
- Горячая вода: отдельно теплоноситель и тепловая энергия, затем сумма.
- Округление денег до копеек (`MidpointRounding.AwayFromZero`).
- Value objects: `Amount`, `Tariff`, `Normative`, `OccupancyPeriod`, `ServiceType`.
- Репозиторий аккаунта и Unit of Work через `DbContext`.
- Обработчик команды расчёта.

## Как запустить

```bash
dotnet run --project ToSobesHz.csproj
```

Приложение попросит данные в консоли и выведет начисления.

## Ограничения

- Показания счётчика пока заглушка — объём должен передаваться извне.
- Провайдеры тарифов и нормативов отдают тестовые значения.
- Нет тестов и валидации пользовательского ввода.
